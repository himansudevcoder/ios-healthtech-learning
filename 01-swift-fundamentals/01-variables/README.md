# Lesson 01 — Swift Variables

**Learning Day:** 02  
**Topic:** Variables and Constants  
**Language:** Swift  
**Practical Example:** Daily Water Tracker

## Objective

Understand how Swift stores values and how variables can be used in a practical iOS application.

## Concepts Learned

- `var` declares a variable whose value can be reassigned.
- `let` declares a constant that cannot be reassigned.
- Variables have meaningful names.
- `print()` displays values in the output.
- SwiftUI can display a variable using string interpolation.

## Practical Example

```swift
var waterConsumed = 500

waterConsumed = 750

let dailyGoal = 2000
```

## SwiftUI Implementation

Displayed the water intake using:

```swift
Text("\(waterConsumed) ml")
```
